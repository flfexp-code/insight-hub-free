# 경제·산업 인사이트 허브 — 무료 3차 버전 · 핵심 브리핑

관심 기업의 뉴스와 공식 연구자료를 연결하여 기업 영향·대응 조건을 검토하는 한글 개인용 웹앱입니다.

앱: https://insight-app-free-jeaigezue99ssijooexnga.streamlit.app/
앱 접근은 비공개이며, 소유 계정으로 로그인합니다. GitHub 코드와 수집한 기사 메타데이터는 공개입니다.

## 배포 상태

3차 버전을 GitHub와 운영 앱에 반영했습니다. 앱은 비공개입니다. 실제 화면에서 관심 기업 추가·해제·새로고침 복원과 기업별 분석 전환을 확인했습니다. 기본 3개 기업을 적용한 GitHub Actions 수집도 성공했습니다. 자유형 AI 기능은 계정 미연결로 비활성화되어 있습니다.

## 이번 기능

- 기본 화면은 **취업 준비·경제 현안용 핵심 브리핑 최대 10건**
- 최근 3일, 기업당 최대 2건·경제 현안 최대 4건. 중요한 후보가 적으면 10건을 채우지 않음
- 기업의 사업·경영 과제, 금리·물가·환율 등 우선. 선정 이유와 면접 준비용 질문 표시
- 유사 제목·도로공사 배구 기사·사진·부고·단순 협약·행사는 기본 제외. 인사·승진·내부 채용 논란은 수집·저장·전체 화면·AI 입력에서 항상 제외
- 그 밖의 후보는 `전체 검색 자료`에서 필요할 때 조회

- 기본 관심 기업: 한국서부발전, 한국도로공사, 한국토지주택공사(LH)
- 관심 기업 등록·해제: 최대 10개. 기업명·약칭·사업 분야·사업 키워드 입력
- 개인 목록은 현재 브라우저에 보관. JSON 파일로 내려받기·다른 기기 불러오기
- 기업명 직접 등장 기사와 사업·파급 경로로 연결한 기사를 구분
- 단순 MOU·협약·행사·기부·지원금 전달·채용 등은 기본 제외
- 지원 규모·정책 조건이 있는 보조금과 사업 규모가 있는 협약은 원문 검토 후보로 유지
- 공식 자료의 진단 → 기업 사업 조건 → 영향·대응 제안 → 반대 경로·예외 → 확인 지표
- 두 현상에 대한 기사 근거가 있을 때 교차 영향 가설 표시
- 한국은행·산업연구원·KDI·한국교통연구원의 검토한 공식 근거 6개와 원문 링크
- 새 공식 자료의 제목·링크 후보를 일일 갱신. 본문 검토 전 후보와 검토한 근거 구분
- CSV·관심 기업 목록·심층 분석용 근거 자료 내려받기

## 분석의 두 단계

현재 즉시 쓸 수 있는 것은 **검토한 보고서 요지와 기사 제목을 규칙으로 연결한 조건부 초안**입니다. 기사 본문을 읽거나 기업의 손익 수치를 계산하지 않습니다. 보고서의 주장과 앱의 대응 제안을 구분하고, 과거 전망을 최신 전망으로 사용하지 않습니다. 제목 선별은 홍보 의도 자체를 판정하지 않습니다.

**자유형 AI 심층 초안은 코드만 준비했고 계정 연결 전입니다. 실제 AI API 호출은 아직 검증하지 않았습니다.** API 키와 무료 프로젝트 확인값이 모두 없으면 요청하지 않습니다. 무료 Gemini 프로젝트의 결제 미연결 여부를 확인한 후 활성화할 수 있습니다. 이 기능의 연결·계정 승인은 별도로 진행합니다. 사용 한도에 닿아도 유료 승격·모델 변경·재시도하지 않습니다. 무료 여부는 키만으로 자동 판별할 수 없으며, 사용자가 해당 프로젝트의 결제를 켜면 비용이 생길 수 있으므로 결제 미연결 프로젝트에서만 활성화해야 합니다.

현재 ChatGPT에서 심층 검토하려면 앱의 `심층 분석용 근거 자료 내려받기` 자료를 대화에 붙여 넣을 수 있습니다. 앱이 ChatGPT 구독을 자동 호출하지는 않습니다.

## 사용법

1. `핵심 브리핑`에서 추린 기사와 생각해 볼 질문을 봅니다.
2. 왼쪽 `등록 기업 선택`에서 기업을 고릅니다.
3. `관심 기업 뉴스 추가 검색`으로 기업명 및 사업 분야의 최신 RSS를 조회합니다.
4. `기업 인사이트`에서 근거·기업 영향·대응 조건·예외를 확인합니다.
5. `관련 뉴스`에서 기사별 연결 이유를 확인합니다.
6. `관심 기업 등록`에서 새 기업을 입력하고 등록합니다. 다음 방문에도 같은 브라우저의 목록이 복원됩니다.
7. 다른 기기에서는 목록 파일을 불러옵니다. 브라우저 데이터를 삭제하면 파일로 복원해야 합니다.

일일 수집은 피드당 후보를 최대 20건으로 줄이고, 핵심 읽기 목록은 `data/brief.json`에 최대 10건만 저장합니다. 후보 이력은 검색용으로 별도 보관하며 읽어야 할 기사 수와 구별합니다.

기본 3곳과 경제·전력·교통·주택 분야의 뉴스는 매일 오전 7:17(한국시간)에 GitHub Actions가 수집합니다. 개인 브라우저에 추가한 기업은 서버의 일일 명칭 검색에 자동 반영되지 않으며 `뉴스 추가 검색`으로 갱신합니다. 일일 검색 기업을 변경하려면 공개 저장소의 `config.json`을 수정합니다.

## 무료 운영

GitHub 공개 저장소의 표준 ubuntu-latest runner와 Streamlit Community Cloud를 사용합니다. 기본 기능에는 API 키·카드·별도 DB·유료 서비스가 필요 없습니다. 비공개 저장소로 바꾸면 Actions 작업이 실행되지 않도록 했습니다. 유료 전환·결제카드 등록·Codespaces는 사용하지 않습니다.

무료 AI 선택 기능은 [Google 공식 가격표](https://ai.google.dev/gemini-api/docs/pricing)와 [결제 문서](https://ai.google.dev/gemini-api/docs/billing)를 확인해야 합니다. 무료 API의 입력·출력은 제품 개선에 사용될 수 있으므로 공개 기사 제목·공식 자료 요지·기업 사업 조건만 사용하고 개인·비밀 자료는 보내지 않습니다.

## 검증

기존 26개 검증을 확장한 인사·승진 제외와 AI 전송 차단을 포함한 63개 테스트가 개발 환경과 GitHub 서버에서 통과했습니다. 서버 검증: https://github.com/flfexp-code/insight-hub-free/actions/runs/38351013087 홍보성 선별, 짧은 영문 약칭, 사업별 대응 차이, 근거 없는 출력 차단, 기업 선택, AI 미연결 시 외부 요청 없음, 존재하지 않는 인용 거부, 무료 한도 오류 시 재시도 없음까지 확인했습니다. AI 응답 검증은 모의 응답으로 점검했으며 실제 Gemini 연결 성공을 주장하지 않습니다.

개발 환경에서 새 기업·주제 수집은 신규 피드 725건, 누적 834건, 실패 피드 0건이었습니다. 공식 자료 후보 15건을 수집했으며 한국은행 목록 연결은 실패하여 상태를 표시했습니다. 외부 피드·기관의 응답은 환경·시점에 따라 달라집니다.

## 파일

- `app.py`: 한글 앱과 근거 표시
- `news_core.py`, `collect_news.py`: 무료 RSS·중복 제거·일일 수집
- `insights.py`: 기업 사업 분야, 선별, 공식 요지, 조건부 연결·교차 가설
- `watchlist_ui.py`: 브라우저 관심 기업 보관·등록·파일 복원
- `ai_insights.py`, `generate_daily_insights.py`: 별도 연결 후 사용하는 선택 AI 기능
- `.github/workflows/`: 수집·검증 자동화
- `tests/`: 핵심·화면·선별·출처·외부 요청 제한 검증
- `DEPLOYMENT_KO.md`, `REVIEW_AND_TESTS_KO.md`: 배포·검증 기록

RSS는 기사 제목·출처·날짜·링크만 보관합니다. 제목이 다른 같은 사건은 중복으로 남을 수 있습니다. Streamlit 앱이 잠들어도 GitHub 수집은 별도로 실행되며 예약 시각은 지연될 수 있습니다.

최종 일일 선별 실행: https://github.com/flfexp-code/insight-hub-free/actions/runs/38351085452 — 핵심 10건 저장. 이 실행에서는 보완 RSS 147건을 받아 누적 1,216건을 검색 자료로 보관했습니다. Google 검색 RSS 11개는 HTTP 503으로 실패하여 최근 저장본을 함께 사용했고, 한국은행 새 자료 목록은 후보를 찾지 못해 상태를 표시했습니다. 앱이 모든 피드를 항상 갱신했다고 해석하지 않습니다.

AI 입력은 기본 화면과 같은 핵심 목록 최대 10건에서 기업 관련 기사만 선택하고 검토한 공식 보고서 요지를 연결합니다. 입력 기사와 출력 출처 번호를 같은 순서로 보관합니다. Google 무료 프로젝트와 키 생성·서버 비밀설정 보관은 승인 대기 중이며 아직 실제 API를 호출하지 않았습니다.
