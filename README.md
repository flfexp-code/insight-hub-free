## 근거와 한계

공개 RSS에서 기사 제목·출처·발행일·링크를 수집합니다. 선택한 핵심 기사 최대 5개, 산업 흐름이 있는 MOU 후보 최대 2개, 오피니언 최대 2개의 공개 HTML 근거를 확인합니다. 원문 전문은 보관하지 않고 출처마다 최대 180단어·1,800자의 문맥 발췌를 저장합니다. 첫 부분뿐 아니라 원인·제약·반론이 있는 문장을 함께 고릅니다. 기본 근거 표시에는 최대 40단어를 쓰고 문맥 발췌는 펼쳐서 확인합니다. 로그인·유료벽·Google 경유 링크를 우회하지 않습니다.

제목만 확인, 공개 요약문 확인, 본문 일부 확인을 구분합니다. 제목만 확인한 기사는 AI의 재서술·추가 해석을 표시하지 않고 원래 제목을 유지합니다. 깊이 학습은 별도 ChatGPT 조사 자료를 검증해 읽습니다. 기사와 보고서의 인용을 각각 요구하고, 모르는 육하원칙 항목을 추측으로 채우지 않도록 합니다. 칼럼은 필자의 의견으로 표시하고 확인한 오피니언이 없으면 비워 둡니다.

공식 자료의 요지는 발행 당시의 진단입니다. 새 보고서 목록 후보를 검토 완료 자료처럼 사용하지 않습니다. 필요한 개념은 주제에 따라 고르며 고정된 목록에서 개수를 채우지 않습니다. 예를 들어 주택용·일반용 요금 기사에서 산업용 변경까지 추정하지 않도록 적용 대상을 구분합니다.
