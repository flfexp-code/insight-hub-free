# PT PDF 한글 폰트

`PTKorean.ttf.gz.b64`는 Android Open Source Project의 DroidSansFallback.ttf에서 한글 11,172자, 한글 자모, 라틴 문자와 기본 기호를 남긴 서브셋을 gzip/base64로 보관한 것이다. 앱 실행 중 외부 다운로드 없이 디코딩해 PDF에 필요한 글리프를 포함한다.

원본: https://android.googlesource.com/platform/frameworks/base/+/dba35c0/data/fonts/DroidSansFallback.ttf

라이선스: Apache License 2.0. 동봉한 LICENSE-Droid.txt의 고지 참조. 글리프 서브셋 외에 디자인 변경 없음.
